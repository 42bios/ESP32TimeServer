# DAP MP-1 2U rack insert

Printed enclosure for the NTP server, occupying **two segments** of the
**DAP MP-1 2U modular rack frame**. Includes the front panel with integrated
board mounts and a separate open-back protective cover.

## Download

- [Front panel — Bambu Studio project (.3mf)](NTP_MP1_2U_V25_Front_3_Parts_Bambu.3mf)
- [Rear protective cover (.stl)](NTP_MP1_2U_V25_Open_Back_Cover.stl)

## Printing

The front contains three colour parts: **base**, **text and satellite**, and
**border and accents**. Assign your filaments in Bambu Studio and keep the parts
assembled. Print with the display side facing the build plate; print the cover
separately.

The project uses an H2D profile with a **0.4 mm nozzle and 0.2 mm layers**.
Select your printer and materials, and check supports before printing.
