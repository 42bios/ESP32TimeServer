# Project photo

`p4-oled-rack-server.png`: photograph of the custom build, supplied by 42bios.
The OLED content was completed using the built-in Imagegen tool to replace a partial
refresh captured in the original photo. Displayed values are illustrative, not live
telemetry or evidence of measured accuracy.

## Editing prompt

Use case: precise-object-edit / compositing. Edit target: actual photograph of the
user's 3D-printed black and turquoise ESP32 GNSS NTP time server. Minimal localized
repair for a GitHub README project photo. Preserve enclosure shape, screws, printed
branding, satellite, antenna connector/cable, unplugged Ethernet port, textures,
background, warm lighting, focus, perspective and square framing. Change only the
existing black OLED glass rectangle. Replace the interrupted refresh with a complete,
readable monochrome cyan-white 256x64 pixel display at realistic restrained brightness.
Top left: UTC and GNSS / PPS LOCKED. Large clock: 13:05:17. Right column: STRATUM 1,
NTP READY, ETH NO LINK, REQ 0. Thin separators. Bottom: GNSS OK SAT 09, PPS OK, UP 0h.
Fit all text inside the screen; no cropped digits, additional IP, watermark or border.

## Web interface logo

`front-panel-satellite.png` reuses the white satellite and cyan arcs from the
project's V24/V25 front artwork. Rasterized directly from the existing CAD artwork
polygons, with transparency; no external icon, image service or font is required.
The same asset is embedded in `main/web_brand.inc` for both firmware pages.

`web-status.png` is a browser capture of the actual ESP status page after the
device-themed firmware update. Values are a momentary commissioning snapshot.
